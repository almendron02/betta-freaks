# Betta Freaks Owner and Founder Questionnaire

## Purpose

This questionnaire collects the business rules, product information, operational details, and written content needed to continue building the Betta Freaks store.

Visual design decisions can be reviewed later. The immediate goal is to define how the real store operates so the database, owner tools, checkout, inventory, policies, and customer communication match the business.

## How to complete this document

- Type each answer after **Answer:**.
- If a decision has not been made, write **Undecided** and name who will decide it.
- Items marked **NEXT MILESTONE BLOCKER** are needed before real inventory, authentication, or Stripe test checkout can be completed.
- Items marked **BEFORE LAUNCH** may be finalized later, but live sales cannot begin without them.
- If the owner cannot complete the full document immediately, complete **Section 14: Final decisions for the next development milestone** first, then return to the detailed sections.
- Do not include passwords, API keys, bank information, government identification numbers, or payment-card information in this document.
- Provider credentials will be added later through protected environment settings, not through chat, email, or this questionnaire.
